# Changelog

## v3.1 — Smart Scene Edition (2026-11-26)
- Added automatic sentence-based scene detection.
- Scene timing adjusts to text length and normalizes to 30 seconds.
- Added scene caption/timing editor.
- Added text size adjustment and wrapping.
- Added caption fade transitions.
- Preserved offline preview and CPU-powered FFmpeg MP4 export.

## Known limitations
- Browser preview may differ from exported MP4.
- Local FFmpeg and Python must be installed.
- Full render has not been verified on every Windows configuration.
